# proxy-assets

代理配置的产物仓库：规则集、覆写脚本、各内核的配置与模块。

## 说明

按内核分目录。`mihomo/` 由生成工具同步，手工改动会在下次同步时被覆盖；其余目录手写或来自上游副本。

```
mihomo/         规则集与覆写脚本
quantumult-x/   配置、重写、脚本、分流
loon/           插件
icons/          图标，跨内核共用
```

## 来源

部分内容取自 [ddgksf2013](https://github.com/ddgksf2013)
